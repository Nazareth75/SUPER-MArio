CASTILLO ROSADO - SPRITES SEPARADOS

Cada elemento está en un PNG individual y organizado por carpetas.

UNITY:
1. Descomprime este ZIP.
2. Arrastra la carpeta Castillo_Rosado_Sprites_Separados a Assets/Sprites/.
3. Selecciona los PNG.
4. Texture Type: Sprite (2D and UI)
5. Sprite Mode: Single
6. Filter Mode: Point (no filter)
7. Compression: None
8. Apply.

NOTA:
Estos sprites proceden de una ilustración generada, no de los assets oficiales de Nintendo.
Los recortes se han preparado como elementos individuales para prototipado académico.
